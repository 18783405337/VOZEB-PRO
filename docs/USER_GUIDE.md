## 快速开始

### 注册账号

1. 访问 VOZEB PRO 首页
2. 点击「注册」按钮
3. 填写用户名、邮箱和密码
4. 如果启用了邮箱验证，请输入收到的验证码
5. 点击「完成注册」

**注意事项：**
- 用户名长度 3-20 个字符，只能包含字母、数字、下划线
- 密码长度至少 8 个字符，建议包含大小写字母、数字和特殊字符
- 邮箱用于密码找回和重要通知

### 首次登录

1. 使用注册的用户名和密码登录
2. 首次登录会获得新手积分奖励
3. 进入工作区，开始创作之旅

### 工作区导航

登录后，您会看到左侧导航栏，包含以下主要功能：

- **统一 Agent**：多模态 AI 创作会话
- **图片工作台**：文生图、图生图
- **视频工作台**：文生视频、图生视频
- **Canvas**：可视化创作画布
- **短剧**：短剧生产流程
- **提示词库**：公共和个人提示词
- **我的素材**：管理所有创作素材
- **个人中心**：账户信息和设置
- **充值中心**：购买积分和套餐

## 账户管理

### 个人资料

在「个人中心」可以管理您的账户信息：

1. **修改头像**：点击头像上传新图片
2. **更新资料**：修改昵称、简介等信息
3. **修改密码**：需要验证旧密码
4. **邮箱绑定**：绑定或修改邮箱

### 找回密码

如果忘记密码：

1. 在登录页点击「忘记密码」
2. 输入注册邮箱
3. 查收验证码邮件
4. 输入验证码设置新密码
5. 使用新密码登录

### 账号安全

**保护您的账户安全：**
- 使用强密码，定期更换
- 不要将密码告诉他人
- 注意识别钓鱼网站
- 如发现异常登录，立即修改密码

### 数据导出

您可以导出个人数据：

1. 进入「个人中心」
2. 点击「数据导出」
3. 选择要导出的数据类型
4. 系统会生成导出文件
5. 下载到本地保存

### 注销账号

如需注销账号：

1. 进入「个人中心」
2. 点击「注销账号」
3. 阅读注销说明
4. 确认后提交申请
5. 管理员审核后完成注销

**注意：** 账号注销后数据将被永久删除，请先导出重要数据。

## Canvas 创作

Canvas 是可视化的创作画布，支持拖拽、连线、AI 生成等功能。

### 创建项目

1. 点击左侧「Canvas」菜单
2. 点击「新建项目」
3. 输入项目名称
4. 点击项目卡片进入编辑器

### Drawing 节点（绘图）

**Excalidraw 模式：**
- 手绘风格的图形绘制
- 支持矩形、圆形、箭头、文字等
- 可调整颜色、粗细、填充
- 支持多页面管理

**TLDraw 模式：**
- 更现代的绘图体验
- 支持自由绘制
- 丰富的图形库
- 灵活的布局工具

**基本操作：**
1. 添加 Drawing 节点
2. 选择绘图引擎（Excalidraw 或 TLDraw）
3. 开始绘制内容
4. 系统自动保存
5. 可查看历史版本

### Script 节点（脚本）

Script 节点用于编写文本内容：

1. 添加 Script 节点
2. 输入标题和内容
3. 支持富文本格式
4. 自动统计字数
5. 支持 Markdown 导出
6. 可进行全文搜索

**适用场景：**
- 剧本创作
- 文案编写
- 笔记整理
- 创意构思

### Skill 节点（技能）

Skill 节点可以执行 AI 任务：

1. 添加 Skill 节点
2. 选择技能模板：
   - 图片生成
   - 文本生成
   - 视频生成
   - 音频生成
3. 配置参数
4. 执行 Skill
5. 查看执行结果
6. 结果自动保存

**参数配置示例：**
```json
{
  "prompt": "一只可爱的小猫",
  "size": "1024x1024",
  "quality": "high"
}
```

### 媒体节点

**图片节点：**
- 上传本地图片
- 从素材库选择
- 使用生成的图片
- 支持预览和下载

**视频节点：**
- 上传本地视频
- 从素材库选择
- 使用生成的视频
- 支持播放预览

**音频节点：**
- 上传音频文件
- 从素材库选择
- 使用生成的音频
- 支持播放试听

### 节点连接

节点之间可以建立连接关系：

1. 点击源节点的输出端口
2. 拖动到目标节点的输入端口
3. 松开鼠标建立连接
4. 可以删除或重新连接

**连接作用：**
- 数据流转
- 依赖关系
- 执行顺序
- 参数传递

### Canvas Agent

Canvas Agent 可以自动执行整个流程：

1. 点击「运行 Agent」
2. Agent 分析节点关系
3. 生成执行计划
4. 按顺序执行节点
5. 结果写回各节点
6. 显示执行报告

**适用场景：**
- 自动化工作流
- 批量生成
- 复杂流程
- 智能创作

### 版本管理

Canvas 支持完整的版本历史：

1. 每次保存自动创建版本
2. 点击「版本历史」查看
3. 可以预览历史版本
4. 可以恢复到任意版本
5. 支持版本对比

### 导入导出

**导出项目：**
1. 点击「导出」按钮
2. 选择导出格式（JSON）
3. 下载到本地

**导入项目：**
1. 点击「导入」按钮
2. 选择本地文件
3. 系统自动解析
4. 创建新项目或覆盖

## AI 生成

### 统一 Agent

统一 Agent 是多模态创作入口：

**创建会话：**
1. 点击「统一 Agent」
2. 点击「新建会话」
3. 输入描述性标题
4. 开始对话

**发送消息：**
- 输入文本提示词
- 上传参考图片
- 上传参考视频
- 从素材库选择

**选择 Skill：**
- 图片生成 Skill
- 视频生成 Skill
- 音频生成 Skill
- 文本创作 Skill
- 自定义 Skill

**查看结果：**
- AI 回复显示在对话中
- 生成的媒体可预览
- 可以下载到本地
- 可以保存到素材库

### 图片工作台

专业的图片生成工具：

**文生图（Text-to-Image）：**
1. 输入提示词描述
2. 选择图片尺寸
3. 选择生成模型
4. 设置生成数量（1-4）
5. 点击「开始生成」
6. 等待生成完成
7. 预览和下载结果

**图生图（Image-to-Image）：**
1. 上传参考图片
2. 输入修改提示词
3. 调整参考强度
4. 选择生成参数
5. 开始生成
6. 查看结果

**高级参数：**
- **尺寸**：512x512、1024x1024、1024x1792等
- **质量**：标准、高清、超高清
- **风格**：写实、插画、动漫、概念艺术
- **负面提示词**：排除不想要的元素
- **采样步数**：影响细节和质量
- **引导系数**：控制与提示词的贴合度

**提示词技巧：**
- 使用具体的描述词
- 添加风格和光照信息
- 指定艺术家风格（如适用）
- 使用权重调整重要性
- 参考优秀提示词案例

### 视频工作台

视频生成功能：

**文生视频：**
1. 输入视频描述
2. 选择视频时长（3-10秒）
3. 选择分辨率
4. 设置帧率
5. 开始生成
6. 等待完成（较慢）
7. 预览和下载

**图生视频：**
1. 上传起始帧图片
2. 输入运动描述
3. 设置视频参数
4. 开始生成
5. 查看结果

**注意事项：**
- 视频生成较慢，请耐心等待
- 消耗积分较多
- 建议从短时长开始测试
- 复杂场景可能失败

### 音频生成

文本转语音功能：

1. 输入要转换的文本
2. 选择声音（男声/女声）
3. 调整语速（0.5x - 2x）
4. 调整音调
5. 选择语言
6. 开始生成
7. 试听和下载

### 查看生成历史

所有生成记录都会保存：

1. 在各工作台查看历史
2. 按状态筛选
3. 搜索历史记录
4. 查看详细信息
5. 重试失败任务
6. 删除不需要的记录

## 短剧制作

完整的短剧生产流程。

### 创建项目

1. 点击「短剧」菜单
2. 点击「新建项目」
3. 填写项目信息：
   - 项目名称
   - 剧集数量
   - 画幅比例
   - 平均镜头数
4. 创建成功

### 第一阶段：剧本

**生成剧本：**
1. 输入剧情大纲
2. 选择风格和题材
3. AI 自动生成剧本
4. 可以手动编辑

**剧本格式：**
```
场景一：咖啡厅 - 白天 - 内景

人物：小明、小红

小明：（微笑）好久不见了！
小红：（惊喜）真的是你！
```

### 第二阶段：审核

**内容审核：**
1. 系统自动审核剧本
2. 检查敏感内容
3. 标记潜在问题
4. 人工确认通过

### 第三阶段：角色场景

**添加角色：**
1. 点击「添加角色」
2. 输入角色信息
3. 上传或生成角色图
4. 保存角色卡片

**添加场景：**
1. 点击「添加场景」
2. 描述场景环境
3. 生成场景图
4. 保存场景素材

**添加道具：**
1. 点击「添加道具」
2. 上传道具图片
3. 标记道具属性
4. 保存到素材库

### 第四阶段：分镜

**创建分镜：**
1. 根据剧本创建分镜
2. 每个镜头配置：
   - 镜头类型（远景、中景、特写）
   - 角色出场
   - 场景选择
   - 台词和旁白
   - 时长
3. 排列分镜顺序
4. 预览分镜板

### 第五阶段：生成

**生成镜头：**
1. 点击「批量生成」
2. 系统依次生成每个镜头
3. 显示生成进度
4. 失败镜头可重试
5. 预览所有镜头

**生成配音：**
1. 选择角色声音
2. 自动读取台词
3. 生成对话配音
4. 试听和调整

**生成音效：**
1. 根据场景生成音效
2. 添加背景音乐
3. 调整音量平衡
4. 预览音频效果

### 第六阶段：合成

**添加字幕：**
1. 自动生成字幕文本
2. 调整字幕时间轴
3. 设置字幕样式
4. 预览字幕效果

**视频合成：**
1. 点击「开始合成」
2. 系统使用 FFmpeg 合成
3. 合成视频、音频、字幕
4. 显示合成进度
5. 生成完成通知

**预览成片：**
1. 播放完整视频
2. 检查画面和音频
3. 如有问题可重新调整
4. 满意后导出下载

### 版本管理

短剧支持多版本管理：

1. 保存不同剧本版本
2. 保存不同分镜版本
3. 保存不同成片版本
4. 可以回溯任意版本
5. 对比版本差异

## 常见问题

### 账户相关

**Q: 忘记密码怎么办？**
A: 使用「忘记密码」功能，通过邮箱验证码重置。

**Q: 如何修改邮箱？**
A: 在个人中心修改，需要验证新旧邮箱。

**Q: 账号被封禁怎么办？**
A: 联系管理员了解原因，申诉解封。

### 生成相关

**Q: 为什么生成失败？**
A: 可能原因：
- 提示词违规
- 服务器繁忙
- 上游接口故障
- 参数设置错误

**Q: 生成失败会退积分吗？**
A: 会的，失败任务会自动退还积分。

**Q: 可以重试失败任务吗？**
A: 可以，在生成历史中点击「重试」。

**Q: 生成速度很慢怎么办？**
A: 视频生成通常需要几分钟，图片生成一般30秒内完成。

### 积分相关

**Q: 新用户有多少免费积分？**
A: 具体额度由平台设置，通常100-500积分。

**Q: 积分会过期吗？**
A: 充值积分通常不过期，赠送积分可能有效期。

**Q: 如何快速获得积分？**
A: 充值购买最快，也可以通过每日签到和邀请好友。

### Canvas 相关

**Q: Canvas 支持多人协作吗？**
A: 当前版本不支持，后续可能会添加。

**Q: Drawing 数据会丢失吗？**
A: 系统自动保存，不会丢失。建议定期导出备份。

**Q: 可以导入其他工具的文件吗？**
A: 支持导入 Excalidraw 和 TLDraw 格式。

### 短剧相关

**Q: 短剧生成需要多长时间？**
A: 取决于长度和质量，通常30分钟到数小时。
